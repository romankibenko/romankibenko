### Обо мне

Днём руковожу строительными проектами в крупной девелоперской компании — отвечаю за результат целиком: от документации и подрядчиков до сдачи объекта. Этот же инженерный подход переношу в разработку: вижу систему целиком, понимаю где узкое место, что упростить, а что заложить с запасом.

Пишу **backend на Java и Python**, делаю **Telegram-ботов с LLM**, **REST API**, парсеры и автоматизацию, поднимаю всё на своём VDS. Беру задачи на фрилансе — от ботов и форм до админок и интеграций.

- 🧰 **Стек:** Java · Spring Boot · Python · FastAPI · aiogram · Vue · PostgreSQL
- 🤖 **Профиль:** Telegram-боты, LLM-интеграции, REST API, парсеры, деплой на VDS
- 🔐 **Отдельно:** практикуюсь в кибербезопасности — CTF и bug bounty (Standoff365, web-уязвимости)
- 📈 **Сейчас:** беру коммерческие заказы, расширяю публичное портфолио
